# harness-manager

Panoramic agent-harness dashboard: a snapshot pipeline plus a self-contained single-file app for visualizing and managing the elements of any agent harness (skills, commands, agents, MCPs, env, scripts) — the same pattern as [`jira-traceability-manager`](https://github.com/Lucas-Nahuel-Pinto/jira-traceability-manager), pointed at a harness directory instead of Jira.

## Status

Design in progress. Setup, commands and tabs will be documented here once the first milestone lands.
